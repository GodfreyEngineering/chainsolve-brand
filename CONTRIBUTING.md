# Contributing

Every asset is generated by `src/gen.py` and rendered by `src/render.py`, as the README
describes, so a change is made in the generator and the outputs are regenerated, never
edited by hand. Colours, the mark's geometry and the type choices come from the brand
specification and change only with it.

This repository accepts no external pull requests. Commit coherent changes in the
structured conventional format; pushing needs the owner's confirmation.
